# IMDb Movie Analysis

## 📌 Project Overview

This project focuses on analyzing IMDb movie data using Python and Data Visualization techniques.

The aim is to explore movie ratings, revenue, release years and other important factors to understand trends and patterns in movies.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Analysis Performed

The project includes analysis of:

- Movie ratings
- Movie revenue
- Release year
- Popular movies
- Highest-rated movies
- Revenue trends
- Data visualization using graphs and charts

## 🎯 Objectives

- To understand IMDb movie data.
- To clean and analyze the dataset.
- To identify interesting patterns in movie ratings and revenue.
- To represent the findings using visualizations.
- To gain practical experience in Python and Data Analysis.

## 📁 Project Files

- `IMDM_Movie_Analysis.ipynb` – Jupyter Notebook containing the complete analysis.
